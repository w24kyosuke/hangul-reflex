# Hangul Reflex (ハングル リフレックス)

ハングル1文字の反射タイピングゲームです。ハングルのタイピングにおける「構築速度」と「正確性」を極めることを目的としています。

## 特徴

* **2つのゲームモード**:
  * **通常 (Normal)**: 指定した問題数（10/20/30問）のクリアタイムとスコアを競います。
  * **サバイバル (Survival)**: 制限時間内にどれだけ正解できるかを競うエンドレスモード。正解すると時間が少し回復します。
* **難易度選択**:
  * **Easy (スタンダード)**: 超頻出文字のみ出題されます。
  * **Normal (チャレンジ)**: 低頻度文字もランダムに出題されます。
  * **Hard (リストガチャ)**: 全11,172文字から完全ランダムで出題される無慈悲な難易度です。
* **コレクション要素**:
  * **獲得称号**: プレイ成績や特定条件の達成で様々な称号（アチーブメント）をアンロックできます。
  * **ハングル図鑑**: 出会ったハングル文字とその全体出現頻度を記録し、確認できます。

## 起動方法

本プロジェクトは静的なHTML/CSS/JSで構築されていますが、内部で `fetch` API を使用してローカルのCSVファイル（`kor_Hang.csv`）を読み込んでいます。そのため、ブラウザのセキュリティ制約（CORS）を回避するために、**ローカルWebサーバー** を立ち上げて実行する必要があります。

### 例: Pythonを使用する場合 (Mac/Linux/Windows)
ターミナルでプロジェクトのルートディレクトリを開き、以下のコマンドを実行します。
```bash
python3 -m http.server 8000
```
その後、ブラウザで `http://localhost:8000` にアクセスしてください。

### 例: VS Codeを使用する場合
VS Codeの拡張機能「**Live Server**」をインストールし、`index.html` を右クリックして「Open with Live Server」を選択することで、自動的にブラウザが立ち上がりプレイ可能になります。

## 注意点
* プレイ時は、OSやIMEのキーボード設定を「韓国語入力（ハングル）」に切り替えてください。
